# Winter temperature and respiratory surges in the Northeast

Final project for CMU 90-819 (Python Programming II), by Vitchakorn Poonyakanok.

**Question.** Does winter temperature in the nine Northeast states (CT, ME, MA, NH, NJ, NY, PA, RI, VT) relate to the size, timing, or short-term growth of influenza, RSV and COVID surges, and does it help forecast them?

**Report:** [`output/report/winter_temperature_respiratory_report.docx`](output/report/winter_temperature_respiratory_report.docx) with a PDF copy [`…report.pdf`](output/report/winter_temperature_respiratory_report.pdf).

**Main finding:** temperature's strong link with illness is the shared seasonal cycle. Once that is removed, winter temperature anomalies show no relationship with surge size, timing or growth, and they don't improve forecasts. Chronos-2 forecasts from surveillance data alone cut 4-week-ahead error by 26–31% compared with a naive forecast.

**Everything runs from one notebook:** [`notebooks/Winter_Temp_NSSP.ipynb`](notebooks/Winter_Temp_NSSP.ipynb), saved with all outputs. It needs no other code files. Section 0 builds the cleaned data, defines the features and runs the forecasts, sections 1–7 run the analysis, and section 8 writes the report:

1. **Data quality:** missing values, duplicate keys, value ranges, coverage, ILINet provider drift, county coverage gaps.
2. **Seasonality:** weekly series with 4-week rolling means, every season on one calendar, STL decomposition, 130 years of winter anomalies.
3. **Correlation:** Spearman matrix, raw vs de-seasonalized correlation, lagged correlation, season-level scatter.
4. **Maps:** state and county choropleths, plus an NYT-style arrow map of county winter warming, 1986–95 → 2016–25.
5. **Forecasting:** Chronos-2 (zero-shot) vs persistence and climatology baselines, with and without temperature covariates, in a rolling-origin backtest.
6. **Feature engineering and interactions:** temperature anomaly, cold-snap flag, heating degrees, holiday weeks, momentum, and interaction regressions.
7. **Hypotheses H1–H7:** permutation, cluster-robust, Wilcoxon and block sign-flip tests with Holm correction.
8. **Report:** builds the Word report and its PDF from the saved result tables.

## Data

| Source | Measures | Grain | Coverage |
|---|---|---|---|
| [NOAA nClimDiv](https://www.ncei.noaa.gov/pub/data/cirs/climdiv/) | monthly mean temperature (°F) | county × month | 1895 – Aug 2026 |
| [CDC NSSP via CMU Delphi](https://cmu-delphi.github.io/delphi-epidata/api/covidcast-signals/nssp.html) | % of ED visits for influenza / RSV / COVID | state & county × week | 4 seasons, 2022-23 – 2025-26 |
| [CDC ILINet (FluView) via CMU Delphi](https://cmu-delphi.github.io/delphi-epidata/api/fluview.html) | % of outpatient visits for influenza-like illness | state × week | 16 seasons, 2010-11 – 2025-26 |
| [Census cartographic boundaries (2020)](https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.html) | county and state polygons | county | maps only |

Every variable, key, unit and known gap is documented in [`docs/data_dictionary.md`](docs/data_dictionary.md). SHA-256 hashes of the raw files are in `data/raw/manifest.json`.
